# S&P 500 Market Analysis

## Overview

This project analyzes historical S&P 500 market data using Python and statistical methods to investigate market returns, volatility, and major economic events.

## Tools Used

* Python
* Pandas
* NumPy
* SciPy
* Matplotlib

## Analyses Performed

* Daily return calculations
* 50-day and 200-day moving averages
* 252-day rolling volatility
* Shapiro-Wilk normality testing
* Pearson correlation analysis
* Spearman correlation analysis
* Data visualization

## Key Findings

* S&P 500 returns are not normally distributed.
* Market volatility increased dramatically during the 2008 financial crisis.
* Volatility spiked again during the COVID-19 crash.
* Extreme market movements were concentrated during major economic disruptions.
